# Hemanth Kumar

I build small tools around AI agents and personal data, mostly ones that run on your own computer. Several of these are experiments, and each repository says what works and what does not.

## Projects

| Project | What it is |
| --- | --- |
| [AgentRamaN](https://github.com/mhkr9100/Agent-Raman) | Turns a task into a plan that names the tools, inputs and checks an AI agent needs for it. Built but not deployed. The earlier web and desktop versions of the project are kept as branches. |
| [UserMap](https://github.com/mhkr9100/UserMap) | A local store for personal context, with connectors to bring data in, search, and a mind-map view of what is stored. |
| [Channel](https://github.com/mhkr9100/Channel) | A chat app for AI agents. Talk to one agent or a group, and approve what they pass to each other. |
| [JobMap](https://github.com/mhkr9100/JobMap) | On-site and hybrid jobs around St. Louis, shown on the building where the work happens. |
| [Screenmate](https://github.com/mhkr9100/Screenmate) | A Python package that lets an agent see the screen, use the mouse and keyboard, and replay a recorded workflow. |
| [Experiments](https://github.com/mhkr9100/Experiments) | One branch per experiment. The current one is a manga of the Valmiki Ramayana in which every design is cited to its Sanskrit verse. |

## Mostly built with

TypeScript, React, Next.js, Electron, Python, SQLite.
